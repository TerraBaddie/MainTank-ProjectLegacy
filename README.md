# MainTank
Tank mitigation &amp; incoming-damage analysis addon for Project Legacy /w many features &amp; Save Var DB persistent priority Recent Boss, Major, Minor fight encounter profiles, and diminishing safe lightweight fight history Database structure.

## Installation

1. Remove or replace the previous `MainTank`, `MainTank_Archive`, and `MainTank_History` addon folders.
2. Extract the 3 folders `MainTank`, `MainTank_Archive`, and `MainTank_History` into `Interface\\AddOns\\`.
3. Restart World of Warcraft or reload the UI.
